# Furqan content packs

Downloadable translations and tafsirs for the Furqan Quran app. The app
reads `v1/catalog.json` and downloads the listed files. Each file
is a gzip-compressed SQLite database, checked against the SHA-256 in the
catalog before it is installed.

Only content whose license status is *cleared* or *confirm* is published
here. See `docs/licenses.md` in the app repository.
